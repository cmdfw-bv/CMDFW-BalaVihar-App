**ConversationRow** — a row in the messages list. `kind="group"` shows the class-chat glyph on indigo; `kind="dm"` shows the peer's role-hued initial. Unread count badges in terracotta.

```jsx
<ConversationRow kind="group" name="Junior A — Class chat" scope="JR·A"
  preview="Mrs. Rao: see you Sunday!" time="9:43" unread={3} />
<ConversationRow kind="dm" role="student" name="Diya K."
  preview="did you finish chant 1?" time="8:10" unread={1} />
```
